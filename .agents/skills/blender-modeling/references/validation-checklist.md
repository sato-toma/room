# アセット検証チェックリスト

対象外の項目は「該当なし」、確認していない項目は「未検証」とする。チェックした事実と、合格と判断した根拠を区別する。

## Blender内

- [ ] 対象Sceneと出力対象Objectを特定した
- [ ] Object名、Collection、階層が用途に合っている
- [ ] 寸法、原点、位置、回転、スケールを確認した
- [ ] Unity向けの場合、原点位置が用途に合い、回転・スケールの適用方針を確認した
- [ ] メッシュ形状と法線を、用途に必要な範囲で確認した
- [ ] Material、UV、Textureを必要に応じて確認した
- [ ] 不要なObjectやデータが出力対象に含まれていない
- [ ] 保存先とファイル名を確認した

## エクスポート

- [ ] 出力形式と設定が受け取り側の要件に合っている
- [ ] 変換、単位、軸方向、Material・Textureの扱いを確認した
- [ ] Unity向けFBXの場合、Metric単位、FBX Unit Scale、Forward `-Z`、Up `Y`、Apply Transformの設定を確認した
- [ ] 出力ファイルが指定場所に生成された
- [ ] ファイルの内容または再インポート結果を確認した

## 受け取り側

- [ ] 対象アプリへのインポート結果を確認した
- [ ] 寸法、向き、位置、Material・Textureを確認した
- [ ] 必要なCollider等、受け取り側固有の要件を確認した
- [ ] 実行環境やサービス上での動作を確認した（実施した場合のみ）

Unity、Cluster、CCK固有の条件は、利用中のバージョンに対応したプロジェクト側の資料を参照する。このチェックリスト単独では互換性を保証しない。
