# アセット作成ワークフロー

## 1. 要件を形状と外観に分ける

- 形状: 部品、輪郭、寸法、厚み、接続、原点、配置
- 外観: 色、Material、Texture、粗さなど、必要とされる見た目
- 出力: 用途、形式、単位、座標系、出力先

曖昧な要件や対象アプリ固有の条件は、確定事項と仮定を分けて扱う。

## 2. Sceneと編集範囲を決める

- 既存SceneやObjectの状態を先に確認する。
- 意味のあるObject名・Collection名を付け、関係のある要素をまとめる。
- 既存データを残す必要がある場合は、編集前に複製または別名保存を検討する。
- 不要データの削除は、対象を特定し、必要なら承認を得てから行う。

## 3. モデルを作成する

- まず必要な大きさ・シルエット・部品構成を満たす。
- ポリゴン数や細部の密度は、用途と性能要件に合わせる。根拠のない一律の上限を設けない。
- 法線、面の重なり、穴、非多様体などは、用途に応じて確認する。
- 原点、回転、スケールを確認し、適用変換が必要かどうかは出力先の要件に基づいて決める。

## 4. 外観とデータを整える

- Material、UV、Textureは必要な場合に作成・確認する。
- 使用していないデータを整理するときは、他のObjectから参照されていないことを確認する。
- テクスチャ形式や解像度は、出力先の要件を確認して決める。

## 5. 確認して受け渡す

- [検証チェックリスト](./validation-checklist.md)を用途に応じて使う。
- エクスポート設定は対象形式・受け取り側の仕様に基づいて決める。
- Unity向けFBXでは、[room Blender MCP仕様](./room-blender-mcp.md)に記録した単位・変換・軸設定と、その適用範囲を確認する。
- Blender内の確認と、外部アプリでのインポート確認を区別して報告する。
