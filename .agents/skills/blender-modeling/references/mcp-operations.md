# Blender MCP操作ガイド

## 操作前

- 接続中のBlenderと利用可能なMCPツールを確認する。
- ツールの説明、入力スキーマ、戻り値、実行対象を確認してから呼び出す。
- 現在のScene、Object、選択状態、保存状態を把握する。
- 操作が既存データを上書き・削除するか、ファイルを書き出すかを確認する。

## 操作中

- 確認できたツール機能の範囲内で作業し、存在を確認していないツール名や引数を使わない。
- 複数段階の作業では、各段階の結果を確認してから次へ進む。
- 実行結果が曖昧、失敗、または一部成功の場合は、成功したと推定せず状態を確認する。
- MCPでできない操作を実行したと報告しない。別の手段を使う場合は、その手段が利用可能か確認する。

## 操作後

- 対象SceneやObjectを再確認し、意図しない変更がないか確認する。
- 保存やエクスポートを行った場合は、結果ファイルのパスと存在を確認する。
- 目視確認や外部アプリ確認をしていない場合、その制約を報告する。

## roomのBlender MCP

roomプロジェクトに設定されているMCPの具体的な制約と出力先は、[room Blender MCP仕様](./room-blender-mcp.md)を参照する。このサーバーの機能を、他のBlender MCP環境でも利用可能だと仮定しない。

それ以外の環境では、特定のBlender MCP実装やツール名を前提としない。具体的な機能・引数は、利用中のサーバーが公開する情報を正とする。
